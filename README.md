# Stock-Market-Projects
Stock Market Projects

This repository contains projects where analysis, forecasts, and experiments are explored.

# Content:

# Technical Analisys
Technical analysis experimentation throughout plots, candlestick plots, exponential moving average (EMA), MACD (Moving Average Convergence Divergence).

# Sentiment Analysis
Analysing sentiment on Stock Market related posts by VADER, and TextBlob.

# Forecasting
Predicing the actual value and ahead utilising different algothims as ARIMA, SARIMA, Random Forest, XGBoost, and Prophet.

# Multi-forecasting
Forecasting OHLC (Open, High, Low, Close) with XGBoost.
